Keeping notes as plain files

Plain files outlive every application. A folder of Markdown notes can be read, searched and synced with tools that were written decades ago, and it will still open in decades to come.

The second reason is ownership. When the notes are files, nobody can lock them behind an account, and a backup is a copy of a folder. That is the whole backup story.

What about structure?

Structure comes from links, tags and folders. None of them needs a database; each is a convention that a small program can read again whenever it is needed, so the files stay the single source of truth for everything.

Finally, plain files compose with the rest of the system: version control, text search, scripting, and editors of every kind all work on them without an adapter or an export step in between.
