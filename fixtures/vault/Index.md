# Vault index

- [[Note]] and [[note.md]] (case-insensitive, with extension)
- [[Note|an alias]]
- [[Note#Second heading]] scrolls to the heading
- [[Note#^block1]] a block reference
- [[folder/Deep]] by path, [[Deep]] by unique basename
- [[Missing]] stays unresolved
- [[Twin]] is ambiguous (two notes with that name)

`[[not a link]]` in a code span is left alone.

```
[[nor in a fence]]
```
